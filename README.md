# File Search Engine Project

## Overview
This project implements a C++ based file search engine designed for efficient and fast retrieval of files. It allows users to quickly find files based on various criteria such as filename, content keywords, file size, and modification dates. The engine works by first indexing files in specified directories, then provides a command-line interface for performing searches.

## Features
*   **Fast Indexing:** Efficiently builds and maintains an index of files and their metadata within specified directories, allowing for quick searches later.
*   **Comprehensive Search Capabilities:** Supports searching by:
    *   **Filename:** Find files matching partial or full filenames.
    *   **File Content:** Search for specific keywords or phrases within the content of text-based files.
    *   **File Size:** Filter files based on their size (e.g., greater than, less than, or equal to a certain size).
    *   **Modification Date:** Locate files modified before, after, or on a specific date.
*   **Command-Line Interface:** Provides a simple yet powerful command-line tool for all interactions.
*   **C++ Implementation:** Developed using modern C++ principles and standard libraries, ensuring performance and maintainability.
*   **Designed for POSIX Systems:** Built and tested primarily on Linux/macOS environments, leveraging standard system utilities.

## Project Structure
The project is organized into logical directories:
*   `include/filesearch.h`: Contains core search functionalities, data structures, and class definitions for the search engine.
*   `src/indexer.cpp`: Implements the logic responsible for scanning directories, extracting file metadata, and building the search index.
*   `src/searcher.cpp`: Implements the search query processing logic, taking user input and querying the index.
*   `src/main.cpp`: The main application entry point, handling command-line argument parsing and orchestrating the indexer and searcher.
*   `build/`: This directory is used to store all intermediate build artifacts and the final executable generated by CMake.
*   `tests/`: Contains unit and integration tests to ensure the correctness and reliability of various components.
*   `CMakeLists.txt`: The primary CMake build script that defines how the project is built.

## How to Build
This project uses CMake as its build system, which simplifies the compilation process across different environments.

1.  **Ensure you have CMake and a C++ compiler installed:**
    *   On Ubuntu/Debian: `sudo apt update && sudo apt install build-essential cmake`
    *   On macOS (with Homebrew): `brew install cmake`

2.  **Navigate to the `build` directory:**
    ```bash
    cd build
    ```
    If the `build` directory does not exist, you can create it in the root of your project: `mkdir build && cd build`

3.  **Configure CMake:**
    This command generates the build files (e.g., Makefiles) based on your system.
    ```bash
    cmake ..
    ```

4.  **Build the project:**
    This command compiles the source code and links the executable.
    ```bash
    make
    ```
    The main executable, `filesearch`, will typically be located in `build/src/filesearch`.
